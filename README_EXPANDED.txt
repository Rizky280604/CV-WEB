Web Portofolio & CV Online MUHAMMAD RIZKY - Expanded Edition
==============================================================

Selamat datang Rizky, ini adalah versi website portofolio interaktif yang telah diperluas dan dipadatkan informasi.

CARA PENGGUNAAN:
1. Ekstrak (Unzip) file ZIP ini di komputer kamu.
2. Di dalamnya terdapat 3 file kode utama dan beberapa aset gambar:
   - index.html (Struktur kerangka website - Padat)
   - style.css (Desain visual, Mode Terang/Gelap, Kepadatan & Latar Belakang Kartu)
   - script.js (Logika interaktif dan mode gelap/terang)
   - pnl.png, sma.png, smp.png, sd.png, tk.png, jne.png, pag.png (Aset gambar sekolah/kerja untuk latar belakang kartu)[cite: 3]
3. **PENTING:** Tambahkan 2 file PDF asli kamu ke dalam folder hasil ekstrak yang sama:
   - "cv-ats.pdf"
   - "porto.pdf"
   (Pastikan nama file persis seperti di atas agar tombol download di web bisa berfungsi).
4. Klik dua kali file `index.html` untuk melihat hasilnya secara lokal di browser kamu.
5. Kamu akan melihat latar belakang gambar sekolah/kerja di setiap kartu timeline pendidikan/pengalaman kerja[cite: 3]. Data juga sudah dipadatkan dan Hobi serta Kompetensi BNSP/Pelatihan sudah dimasukkan[cite: 3].
6. Jika sudah puas, upload seluruh isi folder hasil ekstrak ini ke repository GitHub Pages kamu.

KUSTOMISASI:
- Untuk riwayat Pendidikan Tahun yang kosong, buka file `index.html`, cari teks "[cite: Tahun][cite: Tahun]" dll, lalu ganti dengan tahun asli kamu.

Selamat berkarir, padat & interaktif!
